# ELARA

Настольный магазин одежды, аксессуаров и украшений на Python, PyQt6 и SQLite. В каталоге 24 модели и 125 вариантов размера и цвета. Панель сотрудников открывается через ту же форму входа.

## Запуск

Распакуй весь архив. Открой терминал в папке `ELARA`. Нужен Python 3.10 или новее.

**Windows**

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

**macOS и Linux**

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

При первом запуске приложение создаст `db_units/elara.sqlite3` и заполнит её каталогом, демоаккаунтами и 28 заказами. База сохраняется между запусками.

## Демоаккаунты

| Роль | Телефон | Пароль |
| --- | --- | --- |
| Покупатель | `+7 000 000-00-01` | `ElaraClient26` |
| Администратор | `+7 000 000-01-01` | `ElaraStaff26` |
| Директор | `+7 000 000-01-02` | `ElaraStaff26` |
| Сборщик | `+7 000 000-01-03` | `ElaraStaff26` |
| Курьер | `+7 000 000-01-04` | `ElaraStaff26` |
| Оператор | `+7 000 000-01-05` | `ElaraStaff26` |

Без входа доступны каталог, поиск и карточки. Покупатель может сохранять товары, оформлять заказы и смотреть их историю. При оформлении выбираются адрес и способ оплаты. Это демо-оплата внутри приложения.

Администратор управляет товарами, заказами, клиентами и сотрудниками. Директор просматривает сотрудников, редактирует клиентов и заказы, смотрит аналитику. Сборщик и курьер работают со своими статусами заказов. Оператор просматривает заказы и клиентов. В выручку входят оплаченные заказы без отмены.

## Структура

- `db_units/` — база, схема, стартовые данные и запросы для аналитики.
- `logic_units/` — правила каталога, аккаунтов и заказов.
- `ui_units/` — витрина, кабинет покупателя, панель сотрудников и общие виджеты.
- `resources/` — изображения, шрифты и оформление.

Инструкция по замене изображений и таблица артикулов лежат в [Фотографии.md](resources/images/Фотографии.md). Те же изображения можно заменить по одному через **Управление → Товары → Редактировать → Выбрать фото**.
